# 🧠 Quiz App

A responsive Quiz Application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Multiple-choice questions
- Real-time score tracking
- Countdown timer
- Dynamic question rendering
- Responsive UI

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Flow
1. Created quiz questions array
2. Displayed questions dynamically
3. Added option selection logic
4. Implemented score tracking
5. Added timer functionality
6. Displayed final result screen

## 🎯 Learning Outcome
- Improved JavaScript logic building
- Learned timer handling with setInterval()
- Better understanding of DOM manipulation
- Practiced dynamic UI rendering
